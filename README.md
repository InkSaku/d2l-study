# 动手学深度学习学习记录

本仓库用于记录李沐老师《动手学深度学习》课程的学习过程。

## 学习方式

- 对照官方 PyTorch Notebook
- 在 `practice` 中独立手敲代码
- 在 `notes` 中整理知识点和学习总结
- 使用本地 Mac、Python venv、PyTorch 和 JupyterLab

## 目录结构

```text
d2l-study/
├── practice/      # 每章手敲代码
├── notes/         # 学习笔记
├── official/      # 官方代码，本地保留，不上传
├── data/          # 数据集，不上传
└── checkpoints/   # 模型权重，不上传
